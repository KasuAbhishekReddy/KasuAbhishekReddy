## 💻 Projects

### 🚀 Flagship

| Project | What it does | Stack | Link |
| :--- | :--- | :--- | :---: |
| **CivicLoop** | A single citizen photo triggers an autonomous multi-agent LLM pipeline — categorization, deduplication, routing, auto-escalation — on a confidence-gated **Sense → Plan → Act → Reflect** loop, with a Reflection agent that re-routes its own misclassifications. Every decision is published to a realtime, append-only public **Accountability Ledger**. | React 19 · TypeScript · Supabase · PostgreSQL · Google Gemini · Firebase | [Repo](https://github.com/KasuAbhishekReddy/civicloop) |
| **Vasooli — Collection Radar** | Native Android app that scores retailer credit risk 0–100 from a **six-signal weighted engine** computed entirely from a wholesaler's own ledger. An expected-loss model (risk × outstanding exposure) turns a static balance book into a daily ranked collection list. Fully offline-first, every score explainable in plain language. | Kotlin · Jetpack Compose · Room · SQLite | [Repo](https://github.com/KasuAbhishekReddy/vasooli-collection-radar) |

**Engineering highlights**

- 🛰️ Serverless **SLA-Watcher** Firebase Cloud Function that auto-escalates any civic report once its response deadline lapses
- 🔐 Row-Level Security + Realtime subscriptions on Supabase for a tamper-evident public ledger
- 🗺️ Google Maps and Street View integrated into the React 19 frontend over REST APIs and realtime streams
- 📊 Custom **Canvas-rendered** visualizations in Android — aging chart, sparklines, risk gauge — with **zero external charting libraries**
